# Práctica 1 - Programación II



simula estaciones meteorologicas

El programa genera datos de:

Temperatura
Humedad
Presión barométrica

simulan 10 estaciones meteorologicas durante una semana

## Consultas

El programa permite:

1. Consultar la temperatura promedio esperada de una zona
2. Encontrar el día y la hora más calurosos de cada estacion
3. Consultar la fluctuación de la presión barometrica
4. Detectar alertas de bochorno cuando la temperatura supera los 32 °C y la humedad supera el 80 %
